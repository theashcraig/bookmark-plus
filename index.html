03 / Implementation idea

The same bookmarks.
One new display mode.

There's no need for a second bookmarks database. A folder is still a folder. The browser simply remembers how you prefer to display it on the toolbar. This demo also explores darker glass dropdown styling.

✓Right-click → Display as Slide. Switch between dropdown and inline presentation.
✓Independent state. Opening one Slide never closes another; click it again to collapse.
✓Native compatibility. Bookmark contents and order remain part of the existing bookmark model.
✓Overflow and accessibility. Reuse established bar overflow behavior, keyboard access, and screen-reader semantics.
⌘ Conceptual implementation sketch NOT PRODUCTION SOURCE
folder Work { bookmarks: [Support, ServicePoint] displayMode: "slide" } folder Home { bookmarks: [ChatGPT, Facebook] displayMode: "slide" } expandedFolders = { Work, Personal, Banking } onFolderClick(id) { expandedFolders.toggle(id) }
Implementation is conceptual; the display-mode flag and open-state storage would need to be designed for Chromium's bookmark model and browser UI. The interactive demonstration above is HTML/JavaScript, not a modified browser build.
04 / The proposal

Let's make bookmarks useful again.

Bookmark+ is a request for an optional, native Slide display mode for bookmark folders in Brave and Chromium-based browsers. Existing folders and bookmarks remain unchanged. The user gains inline expansion, independent multi-Slide layouts, and quick access without permanent toolbar clutter.
